# Presentación de Redes Industriales

Abre [index.html](index.html) en Edge, Chrome o Firefox. Las nueve páginas se cargan desde esta carpeta y funcionan sin conexión, incluidas las fotografías, el gráfico y la simulación de registro. El enlace al monitoreo de Mburicaó requiere Internet.

- Flechas izquierda y derecha, Anterior/Siguiente o menú superior para cambiar de página.
- Teclas 1–9 para saltar a esas páginas, Inicio/Fin para ir a los extremos y F para alternar pantalla completa.
- P pausa o reanuda el movimiento. En el celular puedes avanzar con un gesto horizontal.
- Pulsa una fotografía del prototipo para ampliarla. Escape cierra la ampliación.
- En **Registro**, corta la conexión, toma varias lecturas y restáurala para ver cómo se vacía la cola en microSD. Usa **Simular crecida completa** para generar la serie de ejemplo cada cinco minutos.

El contenido está en `index.html` y la navegación en `app.js`. La simulación del servidor está en `registro.js`. La portada original se conserva en `sensia-portada.js`. Los dibujos de Sistema, Estación, Registro y Resultados y Conclusiones se editan en `diagramas.js`.

El diseño toma como referencia [SensIA](https://github.com/mathiasag/SensIA-presentacion-shell-lab). La ilustración y las tipografías provienen de esa presentación. Las fotos de montaje proceden de los informes de Proyecto 4. En Visualización se incluyen las capturas facilitadas del [monitoreo público de Mburicaó](https://mburicaocastai.github.io/v1/) y de la tabla Masi del servidor. La última página resume los ensayos de laboratorio documentados en el artículo de Redes Industriales y el segundo parcial de Proyecto 4.

Los seis esquemas de Esquema se extrajeron de las diapositivas 7 a 12 de `documentos/Reportes/P3_final.pptx` y se pueden ampliar desde la galería.

Las tres vistas de Montaje proceden de las evidencias del segundo parcial de Proyecto 4.
